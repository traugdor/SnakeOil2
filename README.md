# SnakeOil2

SnakeOil2 is a dual-bank polyphonic MIDI synthesizer: a Python prototype of a future VST3.
Each of its 6 voices has two complete oscillator banks, each with its own filter and envelopes.

## Install

```bash
python -m venv .venv
pip install -e ".[app,dev]"
```

## Run

```bash
snakeoil2
```
